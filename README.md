#作品名
Asshen Burst

##概要
Unityを用いて制作した爆破ボードゲームです。
プレイヤーは地雷を避けながら聖杯を獲得するように駒を動かします。
盤上にある聖杯を獲得したときに相手に攻撃を加えることができます。先に相手のHPを全損させたほうが勝ちです。
内部の処理をstructで、Viewの部分をUnity側というように作り分けました。

##使用技術
- Unity
- c#
- struct

##実行方法
「スペースキー」を押すと画面が上からの視点に変化します。
プレイヤーは交互に駒を動かしていきます。
駒をクリックすると動かせる範囲が表示されるので、そこをクリックすることで移動することができます。
駒が地雷を踏むと駒が消失します。
